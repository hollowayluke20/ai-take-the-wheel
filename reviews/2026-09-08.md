## WHERE WE ARE
The destination is to build `attw analyze`, a command-line tool that takes a code repository URL or an idea description, breaks it down into components, finds alternative open-source software ("wheels"), gathers evidence, ranks them, presents a cited comparison table and verdict, installs the winning wheel into a temporary copy of the codebase, and proves improvement with tests. This is done when the full pipeline runs on a fixed 10-run test suite (~6 wins, ~2 hard calls, ~2 "keep yours") against a recorded answer key, and the output reports are judged sensible.

The plan was charted today as a new Wayfinder map (`.scratch/attw-prototype/map.md`) along with 6 initial open issues.
